Política de privacidad

Skill de Alexa «Pósit de Salida» · Última actualización: 3 de noviembre de 2026

Responsable

Odón · contacto: odoncm@gmail.com

Qué datos se guardan

La skill solo guarda el texto de las tareas que le dictas (por ejemplo «bajar la basura») y, en las tareas que se repiten, los días de la semana. Esos datos se asocian a un identificador anónimo de usuario que proporciona Amazon y que es distinto para cada skill. La skill no recibe ni guarda tu nombre, email, dirección, ubicación ni grabaciones de voz.

Para saber qué día es en tu casa, la skill consulta a Amazon la zona horaria configurada en tu dispositivo. Este dato no se guarda.

Para qué se usan

Únicamente para recordarte tus tareas cuando se lo pides. No se usan para publicidad, no se analizan y no se ceden a terceros.

Dónde se guardan

En la infraestructura de Amazon Web Services que Amazon proporciona a las skills «Alexa-Hosted», dentro de la Unión Europea.

Cuánto tiempo

Las tareas puntuales se borran cuando confirmas que las has hecho. Las demás se guardan hasta que las borras («borra todas las tareas») o hasta que desactivas la skill. Si quieres que se eliminen todos tus datos, escribe a la dirección de contacto.

Tus derechos

Puedes ejercer tus derechos de acceso, rectificación y supresión, entre otros, escribiendo a odoncm@gmail.com. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos.

Menores

La skill no está dirigida a menores de 13 años.
